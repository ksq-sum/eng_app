# 小步英语 · 初级绘本课

给初级英语学习者做的自用学习 Web App。以完整绘本故事为主线，结合看图阅读、听力、词句理解、跟读复述与读后练习；原有单句课程保留为补充练习。

## 第一本绘本

当前内容已替换为用户提供的《小王子》第一章英文原文，12 个自然段，仅英文。开头缺失的字母已修正为 Once；原有插图与布局不变。

- 原文阅读，按 12 段分页，配英语词汇释义及句型，不提供中文译文。原文难度高于 A1，不标注为 A1 原文。
- 四步学习：读绘本 → 学词句 → 开口说 → 读后练习。读完全部页面才能进入词句环节，4 道理解与迁移题全部答对后标记完成。
- 支持逐句、逐段和整章朗读、停止播放、慢速听、任选句跟读与复述参考。沿用现有 Edge TTS 音色，长文本请求最多等待 120 秒；生成后使用原有缓存。
- 自动在当前浏览器保存阅读页码、学习环节及已答对的练习，可分次学习。完成后重读会重新开始。
- 新绘本没有预录音频；建议用 `start_all.bat` 启动 TTS。仅前端时尝试系统英语语音，取决于设备语音支持，不保证绘本离线朗读可用。原有课程的内置音频仍保留。
- 每日 8 分钟只是练习目标，不是一本绘本的固定时长，按实际停留与练习时间累计。

## 启动

### 方式1：仅前端（原有音频）

需要 Node.js 18 或更高版本，不需要安装任何依赖。

```sh
npm start
```

电脑浏览器打开 `http://127.0.0.1:5188`。不要直接双击 HTML，ES modules 和离线缓存需要通过服务器运行。

### 方式2：Edge TTS 增强版（推荐）🎙️

**新增功能**: 集成免费的 Edge TTS 服务，提供高质量 AI 语音（微软 Edge 同款）。

```sh
# 首次运行：双击 setup.bat 安装依赖
# 然后双击 start_all.bat 启动所有服务
```

或手动启动：

```sh
# 终端1 - 启动 TTS 服务器
start_tts_server.bat

# 终端2 - 启动前端
npm start
```

**特性**:
- ✅ 完全免费，无 API 限制
- ✅ 4 种高质量语音（美式/英式，男声/女声）
- ✅ 自动缓存，相同文本秒开
- ✅ 智能降级，TTS 服务未启动时自动使用原方案

**测试页面**: http://localhost:3000/test_tts.html

详细说明请查看 [START.md](START.md) 或 [TTS_SETUP.md](TTS_SETUP.md)

## 手机安装与限制

正式部署时，把静态资源放到 HTTPS 网站。浏览器支持时可安装到主屏幕；iPhone 可在 Safari 分享菜单选择“添加到主屏幕”。普通局域网 HTTP 可以预览页面，但不能保证安装、离线缓存和麦克风可用；电脑 localhost 可用于开发这些功能。

离线看课需要先联网访问并完成缓存。原有单句课提供内置英语合成音频；新绘本使用 TTS 或系统英语语音，不能保证离线朗读。播放失败时显示提示。语音识别取决于浏览器、权限及网络；不支持时仍可自行跟读，不影响完成课程。识别可能由浏览器将音频发送给它的语音服务，本项目不保存录音、不提供发音评分。

练习弹窗打开、页面可见、未暂停时计时。后台、锁屏与完成页不累计；刷新或退出会保留累计时长，绘本还会恢复阅读页码和学习环节，单句课不会恢复课内步骤。完成一课不自动记为八分钟。

进度在 localStorage 中，不跨设备同步。清除网站数据或换浏览器后不会保留。当前内容是一本绘本和六节补充单句课，不是完整长期课程，也没有 AI 自由对话服务。

## 文件与后续扩展

- `picturebook.js`：绘本故事、词汇、句型和练习数据；`book-art.js`：原创矢量插图；`book-reader.js`：四步学习界面。
- `lessons.js`：汇总绘本和原有单句课程；`book.css`：绘本桌面与手机样式。
- `app.js`：页面和练习交互；`state.js`：数据校验和日期统计。
- `audio.js`：音频播放与系统朗读回退；`audio/`：24 段英语合成音频。修改课程后，在安装英语音源的 Windows 上执行 `powershell -NoProfile -ExecutionPolicy Bypass -File tools/generate-audio.ps1` 重新生成，并同步更新 `sw.js` 的音频列表及缓存版本。
- `styles.css`：响应式布局；`server.js`：零依赖开发服务器。
- `sw.js`：离线缓存。发布资源更新时同步递增缓存版本，关闭旧页面后重新打开以激活新版本。

后续先根据第一本绘本的使用反馈调整难度和阅读体验，再扩充系列故事与复习计划。需要原生安装包时可在这套 Web 基础上接入移动端容器。账号同步、真人音频和 AI 对话需要单独增加服务，密钥不能写在前端。
